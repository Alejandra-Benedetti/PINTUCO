# PINTUCO — tablero (público, sitio web)

Este repositorio solo sirve para publicar el tablero con **GitHub Pages**.
No contiene los Excel fuente (esos viven en el repo privado
[`DATA_PINTUCO`](https://github.com/Alejandra-Benedetti/DATA_PINTUCO));
`datos.js` va **cifrado**.

**No edites nada aquí a mano** — el robot del repo privado actualiza
`datos.js` automáticamente. Si necesitas tocar el diseño o la lógica del
tablero, hazlo en el proyecto original y vuelve a copiar `Tablero.html` /
`etl.js` aquí.

## Configuración (una sola vez)

**Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save.**

La URL pública aparece en esa misma pantalla:
`https://alejandra-benedetti.github.io/PINTUCO/`
